# FPGA & Digital Design Projects

A collection of hands-on FPGA and digital design projects developed
using SystemVerilog and AMD Vivado.

This repository documents my progression in RTL design, functional
verification, and FPGA implementation, from fundamental digital
circuits to more advanced hardware systems.

## Development Environment

- **FPGA Board:** Digilent Nexys A7-100T
- **FPGA Device:** Xilinx Artix-7 (XC7A100T)
- **HDL:** SystemVerilog
- **Development Tools:** AMD Vivado
- **Version Control:** Git and GitHub

## Projects

| Project | Description | Status |
|---------|-------------|--------|
| [01 - LED](01-led/) | Basic FPGA I/O using a switch and LED | Completed |
| [02 - Multiplexer](02-mux/) | 2-to-1 MUX with SystemVerilog testbench and FPGA implementation | Completed |

## Learning Objectives

Through these projects, I aim to develop practical experience in:

- RTL design using SystemVerilog
- Combinational and sequential digital logic
- Writing testbenches and performing functional simulation
- FPGA synthesis, implementation, and timing analysis
- Hardware verification and debugging
- Git-based version control and project documentation

## Repository Structure

Each project is organized to include relevant source files,
testbenches, FPGA constraints, and documentation.

Generated Vivado build files are generally excluded to keep
the repository focused on the design and verification work.
